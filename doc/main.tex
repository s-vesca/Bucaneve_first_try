    \section{Introduction}
    The objective is to design a quadrature incremental position sensor, based on the 
    acquisition of analog signals provided by an {\it IPS (Inductive Position Sensor)},
    and subsequent numerical processing to obtain desired output signals.

    The IPS is an absolute position sensor which outputs voltages proportional 
    to {sine} and {cosine} of the shaft's angular position.
    These signals can be acquired by a microcontroller via an {\it ADC} and 
    processed to extract the position with {\it atan2} operation.

    Finally, the state of the outputs can be obtained dividing the complete 
    revolution into {\it N} angular sectors, corresponding to the desired 
    output {\it PPR (Pulses Per Revolution)}.
